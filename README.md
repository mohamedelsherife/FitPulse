# 🏋️‍♂️ VORTEX Gym Website

## 📖 Overview

**VORTEX Gym** is a modern fitness website designed to provide users with an interactive gym experience. The project includes workout programs, BMI calculation, membership management, trainer booking, user authentication pages, and fitness progress tracking.

The website was developed using **HTML, CSS, JavaScript, Bootstrap, and Chart.js** with a focus on responsive design and user-friendly interaction.

---

## ✨ Features

### 🏠 Home Page

- 🎯 Modern landing page with VORTEX branding.
- 💪 Featured fitness programs.
- 📊 Progress statistics and charts.
- 📈 Program popularity section.
- ⭐ Member testimonials.

### 🏋️ Workout Programs

- 👨 Gender-based workout selection.
- 🔥 Multiple workout categories:
  - 🏋️ Gym
  - ❤️ Cardio
  - 🥊 Boxing
  - 🧘 Yoga
- 📅 Weekly workout schedules.
- 📂 Expandable fitness program plans.

### ⚖️ BMI Calculator

- 🧮 BMI calculation based on height and weight.
- 👤 Gender selection.
- 📋 Health category classification:
  - 🔵 Underweight
  - 🟢 Normal
  - 🟡 Overweight
  - 🔴 Obese
- 💡 Personalized recommendations.

### 👨‍🏫 Trainers & Booking

- 🏅 Trainer profiles.
- 💼 Trainer specialties and information.
- 📆 Session booking functionality.

### 🎖️ Membership & Progress

- 💳 Membership plans:
  - 🥉 Basic
  - 🥈 Pro
  - 🥇 Elite
- 📊 Progress tracking system.
- ✅ Workout logging.
- 🚀 Rank and achievement progression.

### 🔐 User Authentication

- 🔑 Login page.
- 📝 Sign Up page.
- 🖼️ Profile picture selection.
- 👁️ Password visibility toggle.

### 👤 User Profile

- 📇 Personal information display.
- 🎫 Membership information.
- 📅 Workout schedule overview.
- 📈 Fitness progress indicators.
- 🏆 Personal records and achievements.

```bash

```

### 2️⃣ Open the project folder

```bash
cd FitPulse
```

### 3️⃣ Launch the project

Open `index.html` in your browser.

✅ No additional installation is required.
